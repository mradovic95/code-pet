# AI Art Generation Prompts for Code Pet Sprites

5 pets × 5 states = 25 sprite sheets total.
Prompts tailored for free text-to-sprite-sheet tools like SEELE AI, CGDream, Bylo AI, or similar generators.

---

## Sprite Technical Requirements (include in every prompt)

- Format: Horizontal sprite strip, single row, transparent background
- Frame size: 64×64 pixels per frame
- 4-frame strips = 256×64px total (idle, working, planning, waiting_for_action)
- 20-frame strip = 1280×64px total (waking_up only)
- Style: Pixel art friendly, clean outlines, simple shapes, cute/chibi aesthetic
- No text, no labels, no watermarks

## Post-Generation Checklist

1. Ensure all frames are exactly 64×64px
2. Verify transparent backgrounds (no white/colored fills)
3. Check strip dimensions: 256×64 for 4-frame, 1280×64 for 20-frame
4. Export as SVG (preferred) or PNG
5. If PNG: convert to SVG by wrapping with `<image>` element
6. Name files exactly: `idle.svg`, `working.svg`, `planning.svg`, `waiting_for_action.svg`, `waking_up.svg`
7. Place free pets in `assets/pets/{id}/`, premium pets in `assets/pets-dev/{id}/`
8. Test with `npx electron src/app/main.js` and send events with `./test.sh`

## Style Consistency Tips

- Generate all 5 states for ONE pet in the same session before moving to the next
- Keep the same color palette per character across all states
- Maintain consistent character proportions (head-to-body ratio) across states
- The character should be centered in each 64×64 frame
- Leave ~4px padding around the character edges

### Recommendation for Code Pet

Our specific requirements:
- **64×64 pixel frames** in horizontal strips
- **4-frame strips** (256×64) for idle, working, planning, waiting_for_action
- **20-frame strip** (1280×64) for waking_up
- **Transparent backgrounds** required
- **Character consistency** across 5 states per pet
- **Pixel art / chibi aesthetic**

#### Ranked Picks

**#1 — SEELE AI** (Best overall fit)

SEELE AI is the fastest path from text prompt to usable sprite sheet. It outputs animated sprite sheet PNGs with JSON metadata, meaning less manual post-processing than any other free tool. No signup means zero friction to start generating. The commercial license covers distribution in Code Pet. The main work will be prompt-engineering to hit our exact 4-frame and 20-frame strip requirements and resizing output to 64×64 frames.

**#2 — CGDream** (Best for quality)

With 100 free credits per day, CGDream provides enough headroom for iterative refinement across all 25 sprite sheets. The diffusion model output is high quality and handles style consistency well within a session. Generate all 5 states for one pet in a single session to maintain visual coherence. Output will need manual assembly into our horizontal strip format and resizing to 64×64 frames.

**#3 — Bylo AI + Perchance AI** (Best combined workflow)

Use Perchance AI (unlimited, pixel-art-native) to generate reference frames and lock down the visual style for each pet. Then use Bylo AI to generate animation cycles based on those references. This two-step approach gives pixel-art-quality frames with animation-aware sequencing. The main drawback is Bylo's 5 credits/day limit, which means spreading generation across multiple days.

**Not recommended for this project:**
- **Stable Diffusion (ComfyUI)** — Maximum control but the setup overhead (GPU, models, LoRAs, workflows) and frame consistency challenges make it impractical unless you already have a ComfyUI environment configured.
